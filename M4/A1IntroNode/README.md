## O que é uma API REST?

 Uma API-REST é uma interface que permite a comunicação entre diferentes sistemas usando o protocolo HTTP.

## Protocolo HTTP?

 O protocolo HTTP é uma forma de comunicação entre um cliente e um servidor na internet. O cliente (navegador web) que envia uma requisição ao servidor (Nossa API-REST). O servidor, então, responde com uma mensagem que contém o conteúdo solicitado ou um código de status que indica o resultado da requisição.

## Para que usampos uma API-REST?
 
 Uma API-REST é um servidor que troca informações com o cliente usando o JSON como a estrutura de dados.

## O uqe é o JSON?

 O JSON é a sigla de JavaScript Object Notation, sendo um formato de dados baseado em texto que segue a sintaxe do JavaScript e é usado para armazenar e trocar informações entre sistemas, como servidores web (servidor) e aplicativos (cliente).

## NODE.JS

 O Node.js é uma plataforma que permite executar código JavaScript no lado do servidor usando o V8, o motor de JavaScript do Chrome, permitindo usar o JavaScript fora do navegador.
